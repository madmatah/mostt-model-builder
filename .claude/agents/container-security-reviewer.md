You are the container security expert of this repository's code review. First read `.claude/skills/expert-review/expert-contract.md` and follow it.

The code of the models and of their frameworks, and the files that run code when they load, are untrusted. Check that the diff keeps them confined, and that nothing on the host trusts what a container prints or writes more than the rules allow. Name the rule in every finding.

## Scope

Changes to files matching the `paths` of `.claude/rules/container-security.md`. If none of these changed, reply: "No container surface in this diff; review not applicable."

Read first: `.claude/rules/container-security.md`, `.claude/rules/configuration.md` and `.claude/rules/conventions.md` > Input from outside the program.

## Checks

- **The host runs on its own Python and the standard library, isolated** (`.claude/rules/container-security.md` > The host): a host module that imports a third-party package or a library of the steps, directly or through another module; a launcher that drops `-I`, `-S` or `-B`, or a change of `sys.path` outside its bootstrap; a bootstrap that imports a package of the project, or appends a path other than the project's `src` and the real, well-named recipes' own; or a weakened import test.
- **A container step's Python runs under `-I -B`** (`.claude/rules/container-security.md` > The host): a step started without them, through another interpreter, without `--entrypoint`, through an image's own entry point, or on another bootstrap than the image's copy.
- **Root is refused** (`.claude/rules/container-security.md` > The host): an entry point that reads anything before its check of the ids, that forgets one of them, or that exits with another status.
- **uv never builds a package on the host** (`.claude/rules/container-security.md` > The host): `no-build` removed or set to false in the host's `[tool.uv]`, a file other than the root's named `pyproject.toml`, `uv.toml` or `uv.lock`, a uv command on the host that allows a build, or a locks' check that no longer refuses a package without a wheel that installs here.
- **No uv on the host finds the images' environment** (`.claude/rules/container-security.md` > The host): the images' manifest named `pyproject.toml`, or its lock named `uv.lock`, outside a container; a command, gate step, CI step, hook or document that gives either to uv on the host, under any name; or an image or the `lock` step that gives either to uv under another name.
- **The images' lock is resolved only by `./model-build.sh lock`, and installed only by an image's build** (`.claude/rules/configuration.md` > Dependencies): `required-version` dropped from `images/environment.toml`, or no longer the uv of the `uv` image.
- **The host reaches the network only to fetch the sources, resolve the images' lock, build the images, publish the candidate and check a published revision** (`.claude/rules/container-security.md` > The host): a command or a step, other than `fetch`, `lock`, an image build, `publish` and `check-published`, that reaches the network, or a row of the step table other than the core's `lock` and `publish` that gets one; or a `check-published` that sends a token, makes a request before it holds the repository and the revision to their grammars, reads a listing without its bound in size and time, parses it otherwise than strictly, or keeps a download that does not match the build's bytes.
- **A source is fetched over HTTPS alone, and kept only once it matches its pin** (`.claude/rules/container-security.md` > The host): a pin without its full revision, its size or its SHA-256, or by a branch or a tag; a parser of the pins that accepts a key, a type or a value outside its grammar; a URL built from anything but an accepted pin; a curl option dropped or moved, such as `--disable` no longer first, a protocol other than HTTPS, or the size bound; a downloaded file named, renamed or used before its size and its SHA-256 match, a mismatch kept, or a fetched file no longer checked again.
- **A source's name never marks code, a pickle or an archive, unless its pin says it runs code** (`.claude/rules/container-security.md` > The host): a suffix removed from the refused ones, a check on the last suffix alone or in one case only, or an exception that names no reason; a refused suffix accepted without `runs_code_when_loaded = true`, a mark read as anything but a boolean, or a mark that no longer follows the file to the rows that bind it; or a new file marked in a `sources.toml`, which the listing test must then name.
- **The work directory is the user's own, outside the home directory and the clone** (`.claude/rules/container-security.md` > The host): a default work directory; a check dropped or loosened, such as the grammar, a link, the canonical path, the owner, the mode 0700, `$HOME` or the account's home, under or around either, a missing or relative `$HOME`, or the clone, under or around it; or a path read before its grammar is checked.
- **What a container prints or writes is data** (`.claude/rules/container-security.md` > The host): a decision, a path or a command taken from a container's output; output shown, logged or parsed without the filter and the bound; an output opened by path rather than through the descriptor of its judged directory, or followed through a link; an output read into the host's memory when no parser of the host reads it; a written file judged without its kind, owner, mode, setuid and setgid bits, size bound or link count, or an undeclared entry accepted; or a parser of a container's file, such as `step_peaks.py`, `fleurs_check_report.py`, `lock_check.py`, `lock_freshness.py`, `parity_reports.py`, `conversion_report.py`, `inspection_report.py`, `node_placement.py`, `publication_report.py`, `hypotheses.py`, a recipe's `tensor_fixtures.py`, or a reader of its runs with its `token_rendering.py` and `vocabulary.py`, that is not strict and bounded, or that has no refusal tests; or a parser of JSON that decodes a document before it refuses one nested deeper than 32 levels, or whose depth check reads the text more than once; or a parity report read without the name of the parity its recipe declares, or a conversion's report accepted that describes other conversions than the request asked.
- **The token reaches only the publication's container, on its standard input** (`.claude/rules/container-security.md` > The host): a row other than the core's `publish` that takes the token, or a judgment of the step table that no longer refuses it; a token put in an argument, the environment, a request, a file, a message or a `repr`; a refusal that quotes the text it refused; a grammar loosened; a run that keeps its standard input open without the token, or gets the token without `--interactive`; or a container's output logged, filtered or shown in a tail before its redaction, or redacted chunk by chunk without holding back what may begin an occurrence.
- **The candidate is the host's own copy, checked whole before any run reads it** (`.claude/rules/container-security.md` > The host): a candidate file linked rather than copied, copied by path rather than through the judged directory's descriptor, left writable, or written into an existing candidate; a file not searched for the signatures of `file_signatures.py` whatever its format, or an `onnx` or `text` file not held to its structural check of `file_formats.py`; a tensor, node or graph that the walk of `model_graphs.py` misses, such as a sparse initializer, a tensor attribute, a function's default attribute or a subgraph at any depth; a graph rule of `graph_rules.py` dropped or loosened, such as a domain allowed, `metadata_props` or a training graph or a sparse initializer kept, an external tensor outside its declared file, a constant weight of the conversions' input accepted that is not a plain 2-D initializer, or an output of the conversion to 8-bit blocks accepted with a product of a constant weight left unquantized or another count of `MatMulNBits` than its recipe declares; a rule keyed on a file's name or variant rather than where it comes from; or external data accepted by `external_data.py` with a tensor beyond it, an overlap, a gap, padding, or another `onnx` file naming it; a row that binds the candidate and starts its container without judging the inspection's report and the copies again, or an assembly that starts beside the outputs of an earlier inspection.
- **The code of a model runs only in a container** (`.claude/rules/container-security.md` > Confinement): a library of the steps, or a file that runs code when it loads, such as a pickle or a `.nemo`, loaded on the host, or installed in the host's environment by `pyproject.toml`.
- **A container that loads that code has no network, no privilege and none of the host's secrets** (`.claude/rules/container-security.md` > Confinement): a container run without `--network none`, a read-only root, `--cap-drop ALL`, no new privileges, `--ipc none`, the user 65531 or its limits; swap above the memory, a limit of 0 or -1, or a bound of the step table loosened; a tmpfs without `noexec,nosuid,nodev` or its size; a proxy variable, in either case, that a `docker run` or a `docker build` no longer sets empty; a mount of the home directory, the Docker socket, the clone, a secret or a whole directory of sources; a run that binds the candidate's directory, or a file of the candidate that does not serve its variant, rather than its variant's files each by itself; a bound input that is writable; the GPU on a row of a CPU image; or a token or a credential passed in its environment.
- **A file that runs code when it loads reaches only the one image declared to read it** (`.claude/rules/container-security.md` > Confinement): a recipe's `recipe.py` that declares a second image to read such files, or binds one in a row of another image or of a core image; a contract judgment that no longer refuses it; a step that loads the `.nemo`'s checkpoint, unpickles anything from the archive, restores the whole archive rather than its configuration alone, extracts more than the tokenizer's members, extracts without the filter `data` or outside the container's tmpfs, or finds a member by anything but its exact name at the archive's root.
- **A recipe cannot widen the confinement** (`.claude/rules/container-security.md` > Confinement): a field of the contract, in `domain/contract/recipe_contract.py` or a recipe's `recipe.py`, that reaches Docker or the file system without its type, its grammar or its bound; a recipe judged after a command starts rather than when it loads; an entry module outside the recipe's own `steps` package, or the core's for a core image, or found by importing it; a mount of a directory, of an unpinned file or of an undeclared output; an output beyond 8 GiB or without `peaks.json`; a recipe image named like a core image; or a candidate name with a refused suffix, whatever its format.
- **The publication's container holds the token and the network, and runs no code of a model** (`.claude/rules/container-security.md` > Confinement): a `publish` row that binds a source, an earlier output or the GPU, runs in an image that holds a library of a model, keeps the hub online beside another row, or that `step` or `clean` reaches; limits stated as settled before the trial measures them; or the residual risks of its bridge and its token no longer stated.
- **The container user is no one's on the host** (`.claude/rules/container-security.md` > Confinement): a container user other than 65531, or a run that no longer refuses an account or a subordinate range that holds it.
- **Each mount is judged just before the run** (`.claude/rules/container-security.md` > Confinement): a mount bound without the judgment of each entry from the work directory down, a link followed, a directory accepted where a file is declared, or an existing output directory reused; or an output of an earlier step bound without the judgment of its step's directory, of its entries against the names that step declares, and of the file as a written file, or bound as a directory or writable.
- **Cleaning goes through a container** (`.claude/rules/container-security.md` > Confinement): a cleaning that runs on the host over what a container wrote, a cleaning container that mounts more than the directory it empties, or a directory cleaned or removed before its judgment.
- **A build is reproducible** (`.claude/rules/container-security.md` > Images and outputs): a source without its revision, size or hash, a base image by tag instead of digest, a Python package installed without its hash, without `--frozen --no-build` or from another index, a direct dependency of the images not pinned exactly, `exclude-newer` dropped, or a download from an unpinned URL; or a build stage of an sdist that fetches it otherwise than by `ADD --checksum` at its lock's `sdist` entry, downloads a build requirement without its hash or as an sdist, builds with the network, with isolation or without `SOURCE_DATE_EPOCH`, installs its wheel before checking it against `built-wheels.sha256`, or builds a package that the images' dependency metadata does not name.
- **An image is built from a commit, and runs only at that commit** (`.claude/rules/container-security.md` > Images and outputs): an image built from a clone with changes or untracked files, without its label of the tree, or from another context than the archive of the tree it is labeled with; a step that runs an image by its tag or without the check of its label; a `docker build` that takes `BUILDKIT_SYNTAX` or other arguments; or a Containerfile form that its table of accepted forms does not hold, such as a parser directive, a base by tag, a download or a `RUN` outside the accepted ones.
- **Only `lock` resolves the images' lock, and the user reviews its change** (`.claude/rules/container-security.md` > Images and outputs): a lock written to the clone before its judgment, the locks' check and the freshness check; a change not printed, or printed without the filter; a `lock` container that mounts more than the copies of the manifest and the lock and its output, or that keeps a privilege; or the residual risks no longer stated.
- **A file leaves the work directory only once it is verified** (`.claude/rules/container-security.md` > Images and outputs): a candidate assembled before its checks pass, a check skipped or loosened, a candidate that `verify` measures without reading the report of `inspect` again or without judging each of its files as the host's own copy, an output that `verify` measures read without the judgment of its mount, an index of the bench read before its size and its SHA-256 match its pin again, a candidate file whose hash is not taken through the judged candidate directory with its descriptor's facts judged again, a model card rendered from anything but a fresh verification that accepts the build in a clean clone, or a publication that runs without a terminal, without the typed confirmation of its repository, with a card other than the one reviewed, without judging the inspected copies again, or that accepts a report whose files differ from the verification's; and a command that publishes, which only the user runs, run by an agent.

Leave the security of the rest of the code to the security expert, and the wording of documents to the documentation expert.
